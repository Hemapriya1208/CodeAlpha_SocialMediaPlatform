# Social Media Platform

A mini social media platform developed using HTML, CSS, JavaScript, Express.js, and SQLite.

## Features

- User registration and login
- User profiles
- Create and view posts
- Like posts
- Add comments
- Follow and unfollow users
- Follower and following counts
- SQLite database for storing users, posts, comments, likes, and followers

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the VS Code terminal.
4. Install dependencies:
   `npm install`
5. Start the server:
   `node backend/server.js`
6. Open `http://localhost:3000` in your browser.

This project was developed as part of a Full Stack Development Internship to demonstrate basic social media application functionality using frontend and backend technologies.
